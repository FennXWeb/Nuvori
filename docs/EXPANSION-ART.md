# Expansion art

Generated with the built-in imagegen tool. Transparent original atlases are stored in public/assets/evolution-N.png; each cell preserves its creature family index. The six sheets give all 150 evolved forms distinct mature anatomy. Runtime animation deforms the sprites into species-specific walking, hopping, flying and swimming cycles.

## Atlas 1
Use case: stylized-concept. Create a production game sprite atlas on TRUE TRANSPARENT background, perfectly square, exactly 5 columns and 5 rows of equally sized cells, 25 separate full-body creatures. No text, grid lines, props outside cells, shadows, ground or backdrop. All centered within cells, leave 12% safe margin inside EACH cell, feet aligned 82% down cell. Pixel-art-inspired polished 2D RPG sprites, strong readable silhouette, dark outlines and rich shading consistent with the reference image. Reference image is the baby forms, NOT the output: EVERY creature must have an entirely redesigned more mature body, longer limbs, evolved silhouette, adult facial features, distinctive new anatomy. This is not a recolor. Maintain species family order strictly: row1 leaf fox, fire red panda, water bubble otter, cloud owl, electric rabbit; row2 mushroom badger, coral axolotl, stone armadillo, ice penguin, shadow bat; row3 honey bear, crystal snail, moon moth, iron rhino, kelp seahorse; row4 orchid mantis, lava gecko, star deer, moss tortoise, ghost jellyfish; row5 wind ferret, poison frog, sun lion, thunder ram, jade dragon. Make each readable at 80px.
FIRST evolution, physical guardian branch: adolescent but substantially grown, strong grounded body.
